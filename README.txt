TEACHTECH TABLET GUIDE

HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html. It opens in your browser.
4. Use the top navigation to move between the five pages.

HOW TO EDIT
- Text and prices are inside the .html files.
- Colours, spacing and layout are inside style.css.
- Open the files in Notepad or Visual Studio Code.
- Replace the illustrative tablet images with official product image URLs before publishing.

IMPORTANT
Prices are indicative placeholders, not live prices. Verify current model names, specifications and prices before sharing publicly.
The product images are generic illustrative tablet images, not exact model photos.
